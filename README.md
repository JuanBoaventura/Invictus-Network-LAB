# Invictus Network Lab

Laboratório de redes desenvolvido para simular atividades comuns de suporte técnico e infraestrutura de redes.

O projeto apresenta uma interface de dashboard para acompanhamento de dispositivos, diagnóstico de endereços IPv4, cálculo de sub-redes, consulta de comandos de rede e visualização de alertas.

## Funcionalidades

* Dashboard com indicadores da rede;
* Cadastro de dispositivos;
* Edição e exclusão de dispositivos;
* Filtro por status e tipo de dispositivo;
* Verificação simulada da saúde da rede;
* Diagnóstico de endereços IPv4;
* Identificação de rede, broadcast e faixa de hosts;
* Cálculo de sub-redes;
* Consulta de comandos utilizados em redes;
* Sistema de alertas;
* Alternância entre tema claro e escuro;
* Interface responsiva para computadores e dispositivos móveis;
* Armazenamento local dos dados utilizando `localStorage`.

## Tecnologias utilizadas

* HTML5;
* CSS3;
* JavaScript;
* LocalStorage;
* Visual Studio Code;
* Git e GitHub.

## Como executar

1. Faça o download ou clone este repositório;
2. Abra a pasta do projeto no Visual Studio Code;
3. Abra o arquivo `index.html` no navegador;
4. Para uma melhor experiência, utilize a extensão Live Server no VS Code.
